# DoHome

Local control of **DoHome** Wi-Fi lights (RGBW / white bulbs and LED strips) in
Home Assistant — no cloud or app required.

## Features

- RGB color and white color temperature (3000–6400 K)
- Brightness control
- 27 built-in hardware effects (gradients, jumps, strobes)
- Automatic discovery — found lights appear as ready-to-add cards
- Network scan with multi-select, or manual add by IP / hostname
- Reconfigure a device's address without removing it
- Automatic reconnection and standard light-group control
- Localized UI — English, Russian, German, French, Spanish, Italian, Polish

## Setup

After installing, restart Home Assistant; discovered lights show up in
**Settings → Devices & services**.
